# ivanrico-g.github.io

Portafolio personal de Ivan Rico G, desarrollador backend Java. Sitio estático con [Astro](https://astro.build), en español (`/`) e inglés (`/en/`).

## Desarrollo

```sh
npm install
npm run dev      # http://localhost:4321
npm run check    # tipos
npm run build    # genera dist/
```

## Contenido

Todo el texto vive en `src/data/`:

- `profile.ts`: perfil, experiencia, proyectos, stack, formación y certificaciones (cada texto como `{ es, en }`).
- `ui.ts`: textos de la interfaz y del log de arranque.
